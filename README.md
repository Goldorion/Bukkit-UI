# Stats
An unofficial plugin for [MCreator](https://mcreator.net/) allowing you to create custom toasts.

## Important Information
* This is a Java plugin, so you need to enable them in your preferences
* This plugin supports NeoForge 1.21.1, 26.1.2 and Fabric 26.1.2 (version 2.7.4 or higher is required)
* You need to use MCreator 2026.2

## Downloads/Install Instructions
Downloads can be found on the [Release page of this repo](https://github.com/Goldorion/Stats/releases).
The plugin's MCreator page is [here](https://mcreator.net/plugin/123907/stats).

Install like any other plugin: Launch MCreator → Open preferences → Manage plugins → Load Plugin → Find your downloaded zip file → **Restart MCreator**.
